# TrackmaniaRL

TrackmaniaRL is a Python library for building, training, and evaluating reinforcement learning agents in Trackmania 2020. It combines reusable models, training workflows, game integration, and repeatable evaluation.

## Start here

- [Source code and installation guide](https://github.com/TrackmaniaRL/TrackmaniaRL)
- [Python quickstart](https://github.com/TrackmaniaRL/TrackmaniaRL/blob/main/readme/python-quickstart.md) (no game or GPU required)
- [Trackmania quickstart](https://github.com/TrackmaniaRL/TrackmaniaRL/blob/main/readme/quickstart.md)
- [Documentation index](https://github.com/TrackmaniaRL/TrackmaniaRL/blob/main/readme/README.md)
- [PyPI package](https://pypi.org/project/trackmaniarl/)

TrackmaniaRL 1.2.x requires Python 3.12. To try the package in a Python 3.12 project, run: pip install trackmaniarl.
